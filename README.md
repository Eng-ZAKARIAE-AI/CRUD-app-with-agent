# CRUD App with Agent

This is a simple CRUD application that includes an integrated AI agent. 

## Project Structure
- `frontend/`: Contains the frontend application code.
- `backend/`: Contains the backend API and services.
- `main.py`: Entry point for the application.
- `seed.py`: Script to seed the database with initial data.
- `products.db`: SQLite database for the application.

## Setup
This project uses Python. Ensure you have the necessary dependencies installed. The project relies on `uv` for dependency management.

To get started:
1. Setup the environment and install dependencies.
2. Run the `seed.py` script to populate the database.
3. Start the application using `main.py`.
